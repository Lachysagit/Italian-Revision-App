# SAMPLE QUESTIONS, NOT INSTRUCTIONS. Nothing in this file tells the examiner
# how to behave: examiner_first.txt and examiner_ongoing.txt remain the whole
# instruction for the exam. This is the pool of real syllabus questions that
# Session shows the examiner a few of, per turn, for the topic already running.
#
# FORMAT
#   ## <group>   a syllabus topic. The text must match topic_group() in
#                src/topics.cpp exactly, or the group is never drawn from.
#   > <question> a headline question, the kind that opens a topic.
#   - <question> a connecting question, the kind that follows one up.
#   # <text>     a comment. Blank lines are ignored.
#
# Both > and - are drawn from alike today; the mark records which is which so
# that opening a topic can later be treated differently from following one up.
#
# One question mark per line. The examiner is told elsewhere to ask exactly one
# question per reply, so a line carrying two would teach it the opposite.
#
# The group headers are the English syllabus names on purpose: topic_group() in
# src/topics.cpp returns those exact strings for both languages, and they never
# reach the student. Only the questions below them are German.
#
# BEGINNER LEVEL. These questions set the register the examiner imitates, so
# every one of them keeps to the rules the prompt files state: "du" and never
# "Sie", one main clause with the verb second and no subordinate clause, no
# relative or subordinating linker, and open enough that "ja" or "nein" would
# not finish it. A single Sie-form or verb-final question here would teach the
# examiner the wrong level more effectively than any instruction corrects it.

## family life, home and neighbourhood
> Erzähl mir von deiner Familie.
- Wie ist deine Familie?
- Wie viele Personen seid ihr zu Hause?
- Wie viele Geschwister hast du?

- Welche Feste feiert ihr zusammen?
- Wann esst ihr zu Abend?
- Wie hast du früher die Ferien verbracht?
- Wie hast du als Kind Weihnachten gefeiert?
- Welche Haustiere habt ihr zu Hause?
- Welche Tiere magst du?
- Was machst du im Haushalt?

- Wie ist dein Viertel?

- Was machst du abends in deiner Gegend?
- Was gibt es in der Nähe von deinem Haus?
